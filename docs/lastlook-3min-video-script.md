# LastLook 3 分钟演示视频脚本

## 完整口播稿

你已经离家十分钟，突然想起早上煎蛋时用过灶台。

你明明记得自己关了，但越想越不确定。这个时候，普通摄像头只能让你打开监控、拖动回放、自己判断画面里到底发生了什么。LastLook 想解决的，就是这一刻的不确定。

它不只是告诉你“家里很安全”，而是直接给你一张带证据的确认卡片：灶台已确认关闭。

LastLook 是一个由 eufy 室内云台摄像头驱动的出门安全确认工具。它的首版 MVP 只做一件事：确认灶台是否处于用户设定的“全关”状态。

这个问题很小，但很真实。很多人出门后都会反复想：灶台关了吗，卷发棒拔了吗，门锁好了吗。真正折磨用户的，不一定是忘记，而是没有外部证据。越回忆，越不确定。

所以 LastLook 的产品重点不是多录一段视频，也不是做一个复杂的智能家居平台，而是把 eufy 摄像头变成一个离家后的确认动作。它回答的问题不是“家里发生了什么”，而是“我现在能不能放心走”。

第一次使用时，用户把摄像头转到灶台方向，保存一张“全关”基准照片。之后每次离家，系统会触发检查：摄像头转到同一个预设位，拍摄当前照片，和基准照片进行比对，最后在 App 里返回一个清晰结果。

结果只有三种：已确认、无法确认、异常。

现在看 Demo。

我点击“开始出门检查”。页面会依次显示检查流程：确认离家状态、调用摄像头预设位、拍摄当前照片、对比基准照片、生成结果卡片。

第一种是正常结果。系统显示“灶台已确认关闭”，同时展示当前照片和全关基准照片。用户看到的不是一句空提醒，而是可以自己核对的证据。

第二种是无法确认。比如锅具挡住了旋钮，或者画面太暗，系统不会假装已经看懂，而是明确告诉用户“暂时无法确认”，并说明原因。对安全类产品来说，不确定时说不确定，比给出一个看似肯定的答案更可信。

第三种是异常。当前照片和基准照片不一致时，系统会提示“疑似有旋钮未关闭”。用户可以查看证据照片，再决定是否返回处理，或联系家人确认。

技术上，LastLook 没有把首版做成一个泛化的物体识别问题。它采用更稳定、更容易验证的路线：固定摄像头预设位，固定灶台对象，固定旋钮区域，再和用户自己的全关基准照片进行比对。

这样做有三个好处。

第一，识别范围更小，判断更稳定。

第二，判断依据能被用户看懂，不是一个黑盒结论。

第三，Demo 阶段可以先用模拟检查引擎跑通完整闭环，后续接入真实 eufy SDK 时，只需要替换摄像头控制、拍照和设备状态接口，用户流程不需要重做。

在这个闭环里，eufy 摄像头不是一个被动录像机。它的 PTZ 预设位负责回到灶台角度，拍照能力负责生成当前证据，补光和夜视负责夜间可见性，隐私区用于限制不需要识别的家庭区域，设备状态用于判断摄像头是否在线、是否可以执行检查。

从市场角度看，市面上已经有一些重硬件方案，比如更换灶台旋钮、安装断电设备或增加独立传感器。但这些方案通常有安装门槛，也会带来更高成本。

LastLook 的切入点更轻。它不是要求用户再买一个复杂设备，而是让已经放在家里的 eufy 室内摄像头多完成一件每天都可能需要的事。对 eufy 来说，这也是室内云台摄像头的新购买理由：不只是看家，而是在用户离家后完成一次安全确认。

首批用户也很明确：出门后容易反复确认的人，为父母配置家庭安全设备的成年子女，以及城市公寓和排屋家庭。尤其是在灶台、门锁、卷发棒这些“低频出事、高压担心”的场景里，用户需要的不是更多消息，而是一张能让他放心离开的证据卡片。

当前 Demo 已经完成了前端、后台和三种场景的稳定演示。下一步会接入真实设备 SDK，验证三个核心指标：一次检查需要多久，无法确认的比例有多高，以及用户是否愿意持续查看这张确认卡片。

LastLook 先从灶台开始，但它的结构可以扩展到更多出门检查点。它的目标很简单：把“我到底关了没有”的不确定，变成一张可以放心离开的证据。

## 评委问答短答

### 为什么不直接做烟雾报警？

烟雾报警通常发生在风险已经出现之后。LastLook 解决的是离家后的最后一次确认，尽量在用户还没有陷入长时间焦虑前，把不确定变成可以核对的证据。

### 为什么不用通用物体识别？

首版场景很明确：固定摄像头、固定灶台、固定旋钮区域。用用户自己的全关基准照片做比对，更稳定，也更容易解释。

### 为什么会有“无法确认”？

安全类产品不能假装确定。遮挡、过暗、画面不清时，系统应该明确提示无法确认，并展示证据照片，让用户自己做最后判断。

### 当前 Demo 是否接入真实 eufy SDK？

当前版本完成了前端、后台和检查流程演示，使用模拟检查引擎验证产品闭环。真实设备接入时，会替换摄像头控制、拍照和设备状态接口，核心用户流程保持一致。

### 用户会不会觉得被监控？

LastLook 的首版只围绕灶台固定区域做出门检查，不做连续生活分析。隐私区会限制不需要识别的家庭区域，结果也以一次检查卡片呈现，而不是持续监控流。
