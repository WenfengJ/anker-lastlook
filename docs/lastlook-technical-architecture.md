# LastLook 技术架构说明

## 1. 架构目标

LastLook 的技术目标是把 eufy 室内云台摄像头从“远程查看设备”变成“出门安全确认设备”。首版只处理一个检查点：灶台是否处于用户设定的全关状态。

系统不依赖泛化物体识别作为核心判断，而是采用固定机位、固定对象、固定旋钮区域和基准照片比对的方案，让结果更容易验证，也更容易向用户解释。

## 2. 系统模块

| 模块 | 职责 | 当前 Demo 状态 |
| --- | --- | --- |
| App 前端 | 展示检查入口、检查过程、结果卡片和证据照片 | 已实现 |
| 后台 API | 提供设备状态、基准照片、场景切换、检查启动和结果查询 | 已实现 |
| 设备适配层 | 调用 eufy 摄像头预设位、拍照、补光、隐私区和设备状态 | 当前用模拟器 |
| 检查引擎 | 生成检查步骤和三种检查结果 | 已实现模拟逻辑 |
| 证据层 | 保存或返回当前照片、全关基准照片和判断依据 | 已实现演示素材 |

## 3. 数据流

1. 用户设置灶台“全关”基准照片。
2. 系统保存灶台摄像头预设位。
3. 用户离家或手动点击“开始出门检查”。
4. 后台创建一次检查任务。
5. 设备适配层请求摄像头转到灶台预设位。
6. 摄像头拍摄当前照片。
7. 检查引擎对比当前照片和全关基准照片。
8. 系统生成结果卡片。
9. App 展示结论、原因、当前照片和基准照片。

## 4. eufy 摄像头能力映射

| eufy 能力 | LastLook 用法 | 用户价值 |
| --- | --- | --- |
| PTZ 预设位 | 保存灶台角度，检查时自动转回同一视角 | 降低人工寻找画面的成本 |
| 拍照 / 视频帧采集 | 生成当前灶台证据照片 | 让结果有图可查 |
| 补光 / 夜视 | 光线不足时提高画面可见性 | 降低夜间无法确认概率 |
| 隐私区 | 避开不需要识别的家庭区域 | 降低被持续监控的感受 |
| 设备状态 | 判断摄像头是否在线、预设位是否可用 | 避免设备不可用时输出错误结论 |

## 5. 三种结果产生逻辑

### 5.1 已确认

触发条件：

- 摄像头在线。
- 灶台预设位可用。
- 当前照片可见。
- 旋钮区域与全关基准照片一致。

输出：

- 状态：已确认
- 文案：灶台已确认关闭
- 证据：当前照片、全关基准照片、判断依据

### 5.2 无法确认

触发条件：

- 旋钮区域被遮挡。
- 光线过暗或画面模糊。
- 摄像头离线或预设位不可用。
- 缺少有效基准照片。

输出：

- 状态：无法确认
- 文案：暂时无法确认灶台状态
- 证据：当前照片和无法确认原因

### 5.3 异常

触发条件：

- 当前照片与全关基准照片不一致。
- 旋钮位置明显偏离全关状态。

输出：

- 状态：异常
- 文案：疑似有旋钮未关闭
- 证据：当前照片、全关基准照片、异常原因

## 6. 当前 Demo 接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/health` | 服务健康检查 |
| `GET /api/devices` | 读取摄像头、预设位、补光、隐私区状态 |
| `GET /api/baseline` | 读取全关基准照片 |
| `POST /api/baseline` | 更新全关基准照片 |
| `POST /api/demo/scenario` | 切换演示场景 |
| `POST /api/checks/start` | 启动一次出门检查 |
| `GET /api/checks/:id` | 查询检查结果 |

## 7. 真实 SDK 接入方式

当前 Demo 已把设备能力封装在设备适配层中。真实接入 eufy SDK 时，优先替换以下接口：

| Demo 能力 | 真实接入替换点 |
| --- | --- |
| 摄像头在线状态 | eufy 设备状态接口 |
| PTZ 预设位 | eufy 云台控制或预设位接口 |
| 当前照片 | eufy 截图或视频帧采集接口 |
| 补光 / 夜视 | eufy 灯光或夜视状态接口 |
| 隐私区 | eufy 隐私区配置或本地遮罩配置 |

替换原则：

- 不改变用户流程。
- 不改变结果卡片结构。
- 不扩展首版检查点。
- 保留“无法确认”作为安全边界。

## 8. 隐私策略

- 只在用户触发或离家事件触发时检查灶台。
- 首版只关注灶台固定区域。
- 不做持续生活分析。
- 不输出家庭行为总结。
- 遮挡、过暗、设备不可用时返回“无法确认”。
- 证据照片用于本次检查结果展示，不作为社交内容或营销内容。

## 9. 当前边界

- 当前版本不接入真实 eufy SDK。
- 当前版本使用模拟检查引擎和演示素材。
- 当前版本不远程关火。
- 当前版本不承诺真实环境准确率。
- 当前版本的价值验证重点是流程闭环、可解释结果和用户是否愿意查看证据卡片。
