# LastLook 原型图需求说明

## 1. 目标

定义 LastLook MVP 的关键原型画面，用于后续低保真原型、前端页面和参赛 Demo。

本阶段不制作高保真视觉稿，只确定页面结构、核心文案、按钮和状态。

## 2. 设计原则

- 只围绕灶台关闭确认。
- 每张画面只表达一个关键状态。
- 结果必须带证据照片。
- 系统不确定时直接说“无法确认”。
- 页面看起来像安全工具，不像营销页。
- 移动端优先。

## 3. 关键画面一：出门后自动检查中

页面目标：

让用户看到系统正在执行检查，并理解摄像头正在做什么。

主文案：

正在检查灶台

辅助文案：

摄像头正在转向灶台预设位，预计 30 秒内完成。

画面元素：

- 顶部状态：出门检查中。
- 中部进度区域。
- 检查步骤列表：
  - 检测离家状态
  - 转到灶台预设位
  - 拍摄当前照片
  - 对比基准照片
  - 生成结果
- 底部说明：只在本次检查中查看灶台区域。

按钮：

- 次要按钮：返回首页

状态说明：

- 当前步骤高亮。
- 已完成步骤显示完成标记。
- 未完成步骤保持灰色。

证据照片展示方式：

- 检查中不展示大图。
- 可显示一个小的摄像头占位区域，提示“正在拍摄当前照片”。

移动端布局：

- 顶部为页面标题。
- 中部为进度和步骤。
- 底部为隐私说明和返回按钮。

## 4. 关键画面二：灶台已确认关闭

页面目标：

给用户一个明确、可信、可查看证据的确认结果。

主文案：

灶台已确认关闭

辅助文案：

旋钮位置与基准照片一致。可以放心出门。

画面元素：

- 绿色或正向状态标签：已确认
- 检查完成时间。
- 当前照片。
- 基准照片。
- 判断依据：
  - 灶台预设位一致。
  - 旋钮区域与基准照片一致。
  - 摄像头工作正常。
- 检查步骤完成列表。

按钮：

- 主按钮：我知道了
- 次按钮：查看照片

状态说明：

- 这是默认成功状态。
- 不需要引导用户做额外操作。

证据照片展示方式：

- 当前照片放在上方，基准照片放在下方或并排。
- 照片标题分别为“当前照片”和“全关基准照片”。
- 可以用简单框线标注旋钮区域。

移动端布局：

- 顶部为结果标签和主文案。
- 中部为照片证据。
- 下方为判断依据。
- 底部为操作按钮。

## 5. 关键画面三：无法确认，锅挡住旋钮

页面目标：

诚实说明系统无法判断，并给用户查看证据的入口。

主文案：

暂时无法确认灶台状态

辅助文案：

旋钮区域被遮挡。请查看照片后决定是否复查。

画面元素：

- 黄色或中性状态标签：无法确认
- 当前照片，显示锅或阴影挡住旋钮区域。
- 基准照片。
- 判断依据：
  - 摄像头已转到灶台预设位。
  - 当前照片中旋钮区域不可见。
  - 系统没有给出肯定结论。
- 复查提示。

按钮：

- 主按钮：查看照片
- 次按钮：稍后复查
- 次按钮：返回首页

状态说明：

- 无法确认不是失败，而是安全策略。
- 不确定时不输出“已关闭”。

证据照片展示方式：

- 当前照片优先展示。
- 遮挡区域可用框线或提示文字标注。
- 基准照片作为对照。

移动端布局：

- 顶部为状态标签和主文案。
- 中部展示当前照片。
- 下方展示无法确认原因。
- 底部提供复查和返回。

## 6. 关键画面四：异常，疑似未关闭

页面目标：

明确提示用户当前状态与基准照片不一致，需要处理。

主文案：

疑似有旋钮未关闭

辅助文案：

当前照片与全关基准照片不一致。请查看证据照片并处理。

画面元素：

- 红色或警示状态标签：异常
- 当前照片。
- 基准照片。
- 判断依据：
  - 当前照片中有旋钮偏离基准位置。
  - 检查时间。
  - 灶台预设位一致。
- 风险提示：请确认后再离开。

按钮：

- 主按钮：查看照片
- 次按钮：标记已处理
- 次按钮：返回首页

状态说明：

- 异常只表示“疑似未关闭”，不写成绝对事故判断。
- 不提供远程关火按钮，避免承诺不在 MVP 范围内的能力。

证据照片展示方式：

- 当前照片和基准照片并排或上下排列。
- 当前照片中异常旋钮区域可标注。
- 基准照片中对应区域也可标注。

移动端布局：

- 顶部为警示状态。
- 中部为照片对比。
- 下方为判断依据和操作按钮。

## 7. 辅助画面：首页 / 今日确认状态

页面目标：

作为 Demo 起点，让用户能开始检查并看到设备状态。

主文案：

出门前，让 LastLook 再看一眼

辅助文案：

检查灶台是否处于全关状态，并附上证据照片。

画面元素：

- 最近一次检查状态。
- 灶台检查点卡片。
- 摄像头在线。
- 隐私区已设置。
- 基准照片已设置。

按钮：

- 主按钮：开始出门检查
- 次按钮：设置基准照片
- 次按钮：隐私设置

Demo 控件：

- 已确认
- 无法确认
- 异常

Demo 控件只在开发或演示模式展示。

## 8. 辅助画面：灶台基准设置

页面目标：

让用户理解“全关”基准照片是什么。

主文案：

设置全关基准照片

辅助文案：

请确认所有旋钮处于关闭状态。之后每次检查都会与这张照片对比。

画面元素：

- 摄像头预览或基准照片。
- 灶台预设位状态。
- 旋钮区域说明。
- 创建时间。

按钮：

- 主按钮：保存基准照片
- 次按钮：重新拍摄

## 9. 组件清单

### 9.1 结果状态标签

状态：

- 已确认
- 无法确认
- 异常

用途：

- 在检查结果页顶部展示。

### 9.2 证据照片组件

内容：

- 当前照片。
- 基准照片。
- 照片标题。
- 可选标注区域。

用途：

- 所有结果页共用。

### 9.3 检查步骤组件

内容：

- 步骤名称。
- 步骤状态：等待中、进行中、已完成。

用途：

- 检查中页面和结果页共用。

### 9.4 设备状态组件

内容：

- 摄像头在线。
- 灶台预设位可用。
- 补光/夜视可用。
- 隐私区已设置。

用途：

- 首页和隐私设置页共用。

## 10. 原型验收标准

- 至少包含四个关键状态画面。
- 每个结果画面都有当前照片和基准照片入口。
- 页面文案不夸大系统能力。
- 不出现远程关火、保险合作、完整智能家居控制等非 MVP 功能。
- 检查中画面能解释摄像头能力参与流程。
- 无法确认画面能体现产品可信度。
