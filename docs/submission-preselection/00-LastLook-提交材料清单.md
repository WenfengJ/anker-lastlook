## 4. 提交页推荐填写

项目名称：

```text
LastLook
```

一句话介绍：

```text
LastLook 让 eufy 摄像头在用户出门后自动检查灶台，用一张带证据的照片告诉用户是否可以放心离开。
```

项目简介：

```text
LastLook 聚焦一个真实的出门场景：离家后突然怀疑灶台是否已经关闭。用户第一次使用时保存灶台“全关”基准照片，之后系统在出门检查时调用 eufy 摄像头的 PTZ 预设位、拍照、补光/夜视、隐私区和设备状态，生成已确认、无法确认或异常三种结果卡片。首版 MVP 已完成前端、后台和线上 Demo，当前使用模拟检查引擎验证完整闭环，后续可替换为真实 eufy SDK 接入。
```

技术亮点：

```text
首版采用固定机位、固定灶台对象、固定旋钮区域和基准照片比对的技术路线，避免把问题扩大成泛化物体识别。系统在无法确认时明确返回无法确认，不输出虚假的肯定结论。
```
