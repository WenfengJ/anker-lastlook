## 验证目标

验证 LastLook 是否能稳定完成一个明确任务：

用户离家后，系统能否在可接受时间内给出一张可信的灶台确认卡片。

## 核心指标

| 指标 | 定义 | Demo 阶段验证方式 |
| --- | --- | --- |
| 确认耗时 | 从开始检查到结果卡片出现 | 前端流程和后台时间字段 |
| 场景完成率 | 三种结果是否能稳定跑完 | 已确认、无法确认、异常各跑一次 |
| 无法确认率 | 遮挡或暗光时是否返回无法确认 | 使用遮挡和暗光样本 |
| 异常识别准确性 | 旋钮偏离基准时是否返回异常 | 使用预置异常样本 |
| 用户信任 | 用户是否愿意查看证据照片 | 小样本访谈 |

## 当前验证状态

已完成：

- 本地自动测试。
- 线上 Demo 访问验证。
- 三种演示场景验证。
- 前端、后台和部署路径验证。

仍需补充：

- 真实 eufy SDK 接入测试。
- 真实厨房光线和遮挡样本测试。
- 5 到 8 人小样本用户访谈。

## 提交表达边界

可以说明：

- 当前 Demo 已经跑通完整流程。
- 三种结果可以稳定演示。
- 真实 SDK 接入点已预留。

不说明：

- 已经接入真实 eufy SDK。
- 已经证明可以避免厨房事故。
- 已经达到真实环境准确率。
