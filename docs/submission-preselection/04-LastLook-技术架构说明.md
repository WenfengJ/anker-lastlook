## 核心架构

LastLook 由 App 前端、后台 API、设备适配层、检查引擎和证据层组成。

首版只处理灶台检查点。系统保存用户的“全关”基准照片，在检查时调用 eufy 摄像头回到灶台预设位，拍摄当前照片，并与基准照片进行比对，最后生成结果卡片。

## eufy 能力映射

| eufy 能力 | LastLook 用法 |
| --- | --- |
| PTZ 预设位 | 检查时回到灶台视角 |
| 拍照 / 视频帧采集 | 生成当前证据照片 |
| 补光 / 夜视 | 光线不足时提高可见性 |
| 隐私区 | 避开不需要识别的家庭区域 |
| 设备状态 | 判断摄像头是否在线、预设位是否可用 |

## 三种结果

已确认：

- 当前照片可见。
- 旋钮区域与全关基准照片一致。

无法确认：

- 旋钮区域被遮挡。
- 光线过暗、画面模糊或设备不可用。

异常：

- 当前照片与全关基准照片不一致。
- 旋钮位置明显偏离全关状态。

## 当前 Demo 状态

当前 Demo 已完成：

- 前端页面。
- 后台 API。
- 三种演示场景。
- 设备状态模拟。
- 检查流程模拟。
- 结果卡片和证据照片展示。

当前 Demo 未接入真实 eufy SDK。真实接入时，优先替换摄像头控制、拍照、设备状态和隐私区接口。
