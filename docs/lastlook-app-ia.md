# LastLook App 页面信息架构

## 1. 目标

定义 LastLook MVP 的页面结构、页面职责和跳转关系，用于指导原型和前端开发。

MVP 只围绕一个流程：

设置灶台基准照片 -> 开始出门检查 -> 展示检查过程 -> 展示检查结果和证据照片。

## 2. 页面总览

| 页面 | 路由建议 | 目的 | MVP 必需 |
| --- | --- | --- | --- |
| 首页 / 今日确认状态 | `/` | 展示最近检查状态，触发出门检查 | 是 |
| 检查中页面 | `/check/running/:id` | 展示检查步骤和进度 | 是 |
| 检查结果页 | `/check/result/:id` | 展示结果、依据和证据照片 | 是 |
| 灶台基准设置页 | `/baseline` | 设置或查看“全关”基准照片 | 是 |
| 隐私与摄像头设置页 | `/privacy` | 展示摄像头和隐私设置 | 是 |
| 检查点清单页 | `/checkpoints` | 展示灶台检查点和扩展占位 | 可选 |

首版前端可以只实现前 5 个页面。检查点清单页可合并到首页或设置区域。

## 3. 全局导航

移动端底部或顶部只保留轻量入口：

- 今日
- 基准
- 隐私

Demo 模式下可以增加一个开发入口：

- 场景：已确认 / 无法确认 / 异常

该入口只用于演示，不作为正式用户功能展示。

## 4. 页面规格

### 4.1 首页 / 今日确认状态

入口：

- 打开 App 默认进入。
- 检查完成后返回。

核心信息：

- 产品名：LastLook
- 今日状态摘要。
- 最近一次检查结果。
- 摄像头在线状态。
- 隐私区状态。
- 灶台基准照片状态。

主要操作：

- 开始出门检查。
- 查看最近结果。
- 设置基准照片。

异常状态：

- 未设置基准照片：提示先设置“全关”基准照片。
- 摄像头离线：禁用开始检查按钮，提示设备不可用。
- 隐私区未设置：提示前往隐私设置。

跳转关系：

- 点击“开始出门检查” -> 检查中页面。
- 点击“查看结果” -> 检查结果页。
- 点击“设置基准照片” -> 灶台基准设置页。
- 点击“隐私设置” -> 隐私与摄像头设置页。

### 4.2 检查中页面

入口：

- 从首页点击“开始出门检查”进入。

核心信息：

- 当前检查任务。
- 检查步骤列表。
- 当前步骤高亮。
- 预计完成时间。

检查步骤：

1. 检测离家状态。
2. 转到灶台预设位。
3. 拍摄当前照片。
4. 对比基准照片。
5. 生成结果。

主要操作：

- 无主操作，等待检查完成。
- 可提供“取消”作为次要操作，Demo 中可不实现。

异常状态：

- 检查失败：显示失败说明和“返回首页”。
- 超时：显示“暂时无法完成检查”，允许重试。

跳转关系：

- 检查完成 -> 检查结果页。
- 检查失败 -> 首页或检查结果页的失败状态。

### 4.3 检查结果页

入口：

- 检查完成后自动进入。
- 从首页最近结果进入。

核心信息：

- 结果状态。
- 一句话结论。
- 判断依据。
- 当前照片。
- 基准照片。
- 检查时间。
- 检查步骤完成状态。

主要操作：

- 已确认：我知道了。
- 无法确认：查看照片、稍后复查。
- 异常：查看照片、标记已处理。

异常状态：

- 证据照片加载失败：显示占位和重试按钮。
- 缺少基准照片：提示重新设置基准照片。

跳转关系：

- 点击“我知道了” -> 首页。
- 点击“稍后复查” -> 检查中页面。
- 点击“标记已处理” -> 首页。
- 点击照片 -> 照片对比查看层。

### 4.4 灶台基准设置页

入口：

- 从首页进入。
- 首次使用时由首页提示进入。

核心信息：

- 当前基准照片。
- 基准照片创建时间。
- 灶台预设位状态。
- 旋钮关注区域说明。

主要操作：

- 更新基准照片。
- 保存基准照片。
- 返回首页。

异常状态：

- 没有基准照片：显示设置引导。
- 摄像头不可用：提示稍后重试。
- 照片不清晰：提示重新拍摄。

跳转关系：

- 保存成功 -> 首页。
- 返回 -> 首页。

### 4.5 隐私与摄像头设置页

入口：

- 从首页进入。

核心信息：

- 摄像头在线状态。
- 灶台预设位状态。
- 补光/夜视状态。
- 隐私区状态。
- 隐私说明。

主要操作：

- 查看隐私说明。
- 返回首页。

异常状态：

- 隐私区未设置：提示设置后再使用。
- 摄像头离线：提示检查设备。

跳转关系：

- 返回 -> 首页。

### 4.6 检查点清单页

入口：

- 从首页或设置入口进入。

核心信息：

- 灶台：已启用。
- 卷发棒：扩展检查点，暂未启用。
- 门锁：扩展检查点，暂未启用。
- 燃气报警器：扩展检查点，暂未启用。

主要操作：

- 查看灶台检查点。
- 返回首页。

边界：

- 首版不允许用户新增复杂检查点。
- 扩展检查点只作为未来方向展示。

## 5. MVP 路径

### 5.1 首次设置路径

首页 -> 灶台基准设置页 -> 保存基准照片 -> 首页

### 5.2 正常检查路径

首页 -> 检查中页面 -> 检查结果页：已确认 -> 首页

### 5.3 无法确认路径

首页 -> 检查中页面 -> 检查结果页：无法确认 -> 查看照片 -> 稍后复查或返回首页

### 5.4 异常路径

首页 -> 检查中页面 -> 检查结果页：异常 -> 查看照片 -> 标记已处理 -> 首页

## 6. 页面优先级

P0：

- 首页 / 今日确认状态
- 检查中页面
- 检查结果页

P1：

- 灶台基准设置页
- 隐私与摄像头设置页

P2：

- 检查点清单页
- 照片对比查看层

## 7. 原型约束

- 页面文案短，适合手机界面。
- 每个页面只承担一个主要任务。
- 首页不能变成完整智能家居控制台。
- 检查结果必须展示证据照片入口。
- 无法确认状态必须明确表达“不假装确定”。
